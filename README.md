# 🏦 walidXYann

Projet de programmation orientée objet en **C++** réalisé par **Yann CELIK** et **Walid EL ANSSARI**.

## 📌 Description

Ce projet simule un système bancaire capable de :

- 👤 Enregistrer des utilisateurs
- 🏦 Créer et gérer des comptes bancaires
- 💾 Sauvegarder les données dans un fichier `.txt`
- 🔄 Recharger automatiquement les données lors du redémarrage du programme
- 📊 Afficher les informations d’un prêt
- 📈 Calculer les remboursements et les intérêts pour chaque année

Le projet a été développé en **C++ orienté objet** sous **Windows avec WSL2 (Windows Subsystem for Linux)**.

---

## ⚙️ Technologies utilisées

- C++
- Programmation Orientée Objet (POO)
- WSL2
- Linux Shell Script

Clonez le dépôt :

